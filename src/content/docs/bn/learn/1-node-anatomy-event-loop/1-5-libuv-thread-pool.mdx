## এই লেসনে যা শিখবেন

"Node single-threaded" কথাটা শুধু আপনার JavaScript-এর জন্য। কিছু async কাজ — ফাইল সিস্টেম কল, DNS লুকআপ (`c-ares` ব্যতীত), `crypto.pbkdf2`, `zlib` — সত্যিই থ্রেডে চলার মতো, কারণ OS-এর কাছে সেগুলোর নন-ব্লকিং রূপ নেই। libuv সেই কাজ চালায় **thread pool-এ**: ডিফল্টে চারটি OS থ্রেড, প্রথম ব্যবহারে তৈরি হয় আর তখনই environment থেকে সাইজ নেয় — বাস্তবে `UV_THREADPOOL_SIZE` সেট করুন `node` শুরুর আগে; কোডে সেট করা guaranteed নয়, পুল তৈরি হয়ে গেলে কিছুই করে না। তাই ছয়টি পুল কাজ চলে **দুই ঢেউয়ে** — চারটা, তারপর দুটো। এই লেসন ঢেউগুলো দেখায়, আর `UV_THREADPOOL_SIZE` সেগুলোতে কী করে তা-ও।

## ঢেউ দেখুন

এই লেসনের ডেমো ফাইলটি চালান, তারপর পুল দ্বিগুণ করে:

```bash
node code/1-node-anatomy-event-loop/1-5-libuv-thread-pool/demo.js
UV_THREADPOOL_SIZE=8 node code/1-node-anatomy-event-loop/1-5-libuv-thread-pool/demo.js
```

ডিফল্ট সাইজে ছয়টি `pbkdf2` কাজ দুই ক্লাস্টারে শেষ হয় — চারটা একসাথে, তারপর দুটো — আর এই পুরো সময় আপনার JS থ্রেড মুক্ত থাকে। সাইজ ৮-তে ছয়টাই এক ক্লাস্টারে বসে। খেয়াল রাখুন: পুল `UV_THREADPOOL_SIZE` পড়ে প্রথমবার তৈরি হওয়ার সময়; পুল তৈরির পরে কোডে `process.env.UV_THREADPOOL_SIZE` সেট করার কোনো কাজ নেই।
