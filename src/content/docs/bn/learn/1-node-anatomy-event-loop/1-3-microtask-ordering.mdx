## এই লেসনে যা শিখবেন

প্রতিটি লুপ-ফেজের মাঝে — আর প্রতিটি callback-এর পরে — Node এগিয়ে যাওয়ার আগে দুটি **মাইক্রোটাস্ক** কিউ নিষ্কাশন করে: আগে পুরো `process.nextTick` কিউ, তারপর পুরো **Promise** কিউ (V8-এর নিজের মাইক্রোটাস্ক, `await` কন্টিনিউয়েশনসহ)। `setImmediate` আর `setTimeout` মাইক্রোটাস্ক *নয়* — তারা নিজেদের ফেজে অপেক্ষা করে। এই লেসন ডেমো দিয়ে তিনটি নিয়ম পিন করে: nextTick আগে এবং সম্পূর্ণ নিষ্কাশিত হয়; Promise callback শুরু হলে মাঝপথে nextTick ঢুকলেও পুরো Promise কিউ নিষ্কাশিত হয়েই তার পালা; আর কোনো ফেজ চলার আগে দুটি কিউই খালি হয়।

## তিন কিউ, প্রতিটির এক রায়

এই লেসনের ডেমো ফাইলটি চালান:

```bash
node code/1-node-anatomy-event-loop/1-3-microtask-ordering/demo.js
```

দশটি নাম্বারযুক্ত লাইন — আর <em>নাম্বারগুলোই</em> এই লেসন: দেখুন `[1]`–`[2]` (nextTick FIFO) প্রিন্ট হয় `[3]`-এর (প্রথম Promise) আগে — তারপর `[5]`, যেটি Promise callback-এর <em>ভেতর থেকে</em> কিউ করা একটি nextTick, প্রিন্ট হয় পুরো Promise কিউ `[3]`–`[7]` নিষ্কাশন শেষ হওয়ার পরেই। ফেজের কাজ `[8]`/`[9]` সবার শেষে — আর তাদের আপেক্ষিক অর্ডার দুই কিউর পরে দেখানোই ইচ্ছাকৃত: ওটার ওপর ভরসা করবেন না।
