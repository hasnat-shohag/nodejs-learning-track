## এই লেসনে যা শিখবেন

event loop কোনো সাধারণ কিউ নয় — এটি **ফেজের চক্র**। প্রতি পাকে libuv ঘুরে আসে: **timers** (নির্ধারিত সময় পার হওয়া `setTimeout`/`setInterval` callback), **pending** (কিছু I/O রেজাল্ট), **idle/prepare** (অভ্যন্তরীণ), **poll** (নতুন I/O ইভেন্টের জন্য অপেক্ষা ও সেগুলোর callback চালানো), **check** (`setImmediate` callback), তারপর **close** (socket-এর `'close'`-এর মতো টিয়ারডাউন callback)। এই লেসন একে একে এক পাক দেখায়, সাথে সেই একটি অর্ডারিং নিয়ম যা ইন্টারভিউয়ে সত্যিই খোঁচে — I/O callback-এর ভেতর থেকে `setImmediate` জেতে `setTimeout(…, 0)`-কে।

	</p>
</Pitfall>

## এক পাক, চারটি দৃশ্যমান ফেজ

এই লেসনের ডেমো ফাইলটি চালান:

```bash
node code/1-node-anatomy-event-loop/1-2-event-loop-phases/demo.js
```

ক্রম অনুযায়ী এক লুপ-পাক প্রিন্ট করে: **timers** ফেজে 0ms `setTimeout` চলে, **poll** ফেজে সত্যিকারের `fs.readFile` ইভেন্ট পৌঁছায়, **check** ফেজে `setImmediate` চলে — সাথে poll callback-এর ভেতর থেকে শিডিউল করলে অর্ডার উল্টে যাওয়াটাও, যেখানে immediate-কে আর পরের পাকের timers ফেজের জন্য অপেক্ষা করতে হয় না।
