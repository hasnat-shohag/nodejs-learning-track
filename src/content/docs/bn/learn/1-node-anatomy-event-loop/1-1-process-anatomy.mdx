## এই লেসনে যা শিখবেন

চলমান প্রতিটি Node প্রোগ্রামই তিনটি লেয়ার মিলে একটি প্রসেস: **V8** আপনার JavaScript চালায়, **libuv** event loop আর async I/O মেশিনারির মালিক, আর Node-এর **bindings** দুটোকে C++ দিয়ে জোড়ে। এই লেসন সেই স্ট্যাকের একটি গাইডেড ট্যুর — প্রতিটি লেয়ারকে চলমান প্রসেস থেকে প্রিন্ট করা কোনো কিছুর সাথে মেলাবেন, যাতে নামগুলো অ্যাবস্ট্রাকশন না থেকে বাস্তব হয়ে ওঠে।

## তিন লেয়ার, একটি ডেমো

এই লেসনের ডেমো ফাইলটি চালান:

```bash
node code/1-node-anatomy-event-loop/1-1-process-anatomy/demo.js
```

আপনার Node বাইনারি যে প্রতিটি লেয়ারের ভার্সন বহন করে — V8, libuv (`process.versions.uv`) ও Node bindings — সেগুলো `process` অবজেক্ট থেকে সরাসরি প্রিন্ট করে।
