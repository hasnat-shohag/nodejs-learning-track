## এই লেসনে যা শিখবেন

V8 কোনো ইন্টারপ্রেটার নয় — এটি টায়ারিং কম্পাইলার। আপনার কোড শুরু হয় বাইটকোড হিসেবে (Ignition), তারপর হট ফাংশন Sparkplug (বেসলাইন মেশিন-কোড টিয়ার) হয়ে পুরো অপটিমাইজড মেশিন কোডে (TurboFan) ওঠে। অপটিমাইজেশনের সিদ্ধান্ত দাঁড়িয়ে আছে **শেপ**-এর ওপর: একই প্রপার্টি একই ক্রমে বানানো অবজেক্টগুলো একটি **hidden class** শেয়ার করে, যাতে V8 প্রপার্টি অ্যাক্সেস ইনলাইন করতে পারে। শর্তটা হলো একটা বাজেট: এক রিড-সাইট চারটি পর্যন্ত আলাদা hidden class সহ্য করে (polymorphic), এরপর megamorphic হয়ে প্রতিটি রিড ধীর পথে পড়ে। এই লেসন তিনটি তথ্যই মাপে — শেপ বাজেট, megamorphic ধাপ, আর GC স্পেসগুলো যেখান থেকে আপনার pause আসে।

## তিনটি মাপ

এই লেসনের ডেমো ফাইলটি চালান:

```bash
node code/2-v8-memory-modules/2-1-v8-server-view/demo.js
```

ছাপে: `[1]` এক কনস্ট্রাকশন-ক্রম বনাম `[2]` একই রিড-সাইটে তিন ক্রম মিশ্রিত — তিনটি ফর্ক-হওয়া শেপ inline-cache বাজেটের *ভেতরে* থাকে, তাই রিড দ্রুতই থাকে; শেপ ফর্কের দাম তখনই, বাজেট পার হলে — `[3]` সেটাই পিন করে: এক রিড-সাইটে চার শেপ polymorphic cache ধরে রাখে, আর পঞ্চম আলাদা hidden class-ই megamorphic ধাপ যেখানে প্রতিটি রিড ধীর পথ দেয়; `[4]` চলমান প্রসেসের আসল V8 heap স্পেসগুলো, যাতে "young generation" আর "old space" শব্দভাণ্ডার না থেকে মেগাবাইট হয়ে ওঠে — সাথে heap-জুড়ে `heap_size_limit` বনাম যে old-space অঞ্চল `--max-old-space-size` আসলে সীমিত করে।
