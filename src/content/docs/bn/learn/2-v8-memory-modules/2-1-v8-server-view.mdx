## এই লেসনে যা শিখবেন

V8 কোনো ইন্টারপ্রেটার নয় — এটি টায়ারিং কম্পাইলার। আপনার কোড শুরু হয় বাইটকোড হিসেবে (Ignition), আর যে ফাংশন হট চলে সে রি-কম্পাইল হয় অপটিমাইজড মেশিন কোডে (TurboFan)। অপটিমাইজেশনের সিদ্ধান্ত দাঁড়িয়ে আছে **শেপ**-এর ওপর: একই প্রপার্টি একই ক্রমে বানানো অবজেক্টগুলো একটি **hidden class** শেয়ার করে, যাতে V8 প্রপার্টি অ্যাক্সেস ইনলাইন করতে পারে। শেপ ছড়িয়ে দিলে প্রতিটি রিড পড়ে ধীর লুকআপে। এই লেসন তিনটি তথ্যই মাপে — শেপ বিচ্ছিন্নতা, inline-cache ওভারফ্লো, আর GC স্পেসগুলো যেখান থেকে আপনার pause আসে।

## তিনটি মাপ

এই লেসনের ডেমো ফাইলটি চালান:

```bash
node code/2-v8-memory-modules/2-1-v8-server-view/demo.js
```

ছাপে: `[1]` এক কনস্ট্রাকশন-ক্রম বনাম `[2]` তিন ক্রম মিশ্রিত — ছড়ানো সেটটি ~১.৭x ধীর পড়ে কারণ তার hidden class ভাগ হয়ে যায়; `[3]` এক রিড-সাইটে চার শেপ ঘুরে — inline cache ওভারফ্লো করে মেগামর্ফিক লুকআপে পড়ে; `[4]` চলমান প্রসেসের আসল V8 heap স্পেসগুলো, যাতে "young generation" আর "old space" শব্দভাণ্ডার না থেকে মেগাবাইট হয়ে ওঠে।
