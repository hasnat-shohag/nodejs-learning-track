## এই লেসনে যা শিখবেন

আপনি সারাদিন C++ কল করেন: `fs.readFile`, `crypto.pbkdf2`, `Buffer.byteLength` — Node-এর C++ কোরের ওপর JS facade, আর বাউন্ডারিটা আসল seam, তার আসল দাম আছে। থার্ড-পার্টি **অ্যাডন** একই seam বাড়ায় — আর **N-API** হলো সেই চুক্তি যা অ্যাডনকে টেকসই করে: স্থির C ABI, V8-এর অভ্যন্তর থেকে বিচ্ছিন্ন, তাই একবার কম্পাইল করা অ্যাডন রিবিল্ড ছাড়াই Node ভার্সন জুড়ে লোড হতে থাকে। এই লেসন আপনার নিজের প্রসেসের ভেতরের নেটিভ স্ট্যাক ছাপে, বাউন্ডারি টাইম করে, আর দেখায় অ্যাডন প্যাকেজ `npm install` করলে `node-gyp` কী করে।

## seam, মাপা হলো

এই লেসনের ডেমো ফাইলটি চালান:

```bash
node code/2-v8-memory-modules/2-5-native-boundary/demo.js
```

`[1]` `process.versions` ছাপে — node, v8, uv, zlib, openssl, আর `napi` (এই Node কোন N-API লেভেল সাপোর্ট করে) — আপনার প্রসেসে এমনিতেই থাকা C ও C++ লেয়ার। `[2]` `pbkdf2` চালায় ১ বনাম ১০০ হাজার iteration-এ: একই নেটিভ কল, যার কাজ নামে Domain 1-এ দেখা **thread pool**-এ পড়ে। `[3]` ১০ লাখ খাঁটি-JS কল বনাম ১০ লাখ `Buffer.byteLength` কল টাইম করে — প্রতিটি নেটিভ কল বাউন্ডারি পার করে, আর পার্থক্যটা আসল কিন্তু কয়েকগুণ, কোনো স্থির গুণিতক না (মেশিন আর কলভেদে বদলায়; বিদ্যমান Buffer view-তে `byteLength` এমনকি fast path নেয়)। সৎ নিয়মটা এটাই কেনে: **নিজের ক্রসিং মেপে নিন, তারপর কাজ এক পাশে বান্ডেল করুন**; আইটেম-প্রতি পিং-পং করবেন না।
