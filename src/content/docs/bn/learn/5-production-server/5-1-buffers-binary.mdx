## এই লেসনে যা শিখবেন

JS string হলো *character*-এর সিকোয়েন্স; runtime-এর নিচের সব কিছু — socket, file, TLS, crypto — চালায় *byte*। বাংলা string `'হাই'` ৩টি character কিন্তু **৯টি UTF-8 byte**: প্রতিটি character তিন byte, আর `content-length` header, ফাইলের সাইজ, hash — সবাই গোনে ৯, ৩ নয়। **Buffer** হলো Node-এর সেতু: fixed-length byte array with encoding helper, আর — যেটা আচরণ ব্যাখ্যা করে — একটি **TypedArray** subclass, `ArrayBuffer`-এর ওপর `Uint8Array` view। এই এক তথ্যই পুরো gotcha তালিকা দেয়: `Buffer.from(arrayBuffer)` কপি করে না, মেমরি শেয়ার করে (`Uint8Array` দিয়ে লিখলে `Buffer` দিয়ে পড়া যায়); `subarray` হলো zero-copy *alias* — slice দিয়ে লিখলে parent বদলায়; আর decode একটা *পছন্দ* — একই ৯ byte `utf8`-এ পড়লে বাংলা ফেরে, `latin1`-এ পড়লে নীরব mojibake, `hex`-এ দেখায় wire-এ আসলে কী আছে। ভুল decode কখনো throw করে না; চুপচাপ মিথ্যা বলে।
