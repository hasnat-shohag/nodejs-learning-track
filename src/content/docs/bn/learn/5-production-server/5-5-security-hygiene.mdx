## এই লেসনে যা শিখবেন

Naive secret compare byte 0 দেখে প্রথম mismatch-এ থেমে যায় — তাই real token-এর প্রথম ১১ byte মেলে এমন guess বাদ দিতে যেটা byte 0-এ ব্যর্থ হয় তার চেয়ে মাপার মত বেশি সময় নেয়। ডেমো প্রতি position-এ ১০,০০০ compare সময় মাপে, আর লম্বা-prefix guess চলে মাপার মত বেশি সময় — কত শতাংশ মেশিনভেদে; ডেমো নিজের মাপা মান ছাপে: gradient-টাই leak, আর attacker পড়ে এক byte এক byte করে পুরো token তুলে নেয়। `crypto.timingSafeEqual(a, b)` — খেয়াল: `crypto`-তে, `Buffer`-এ নয় — প্রতিটি byte শর্তহীন তুলনা করে, আর একই sweep মাপে সমতল। **Security header** মানে সার্ভার browser-কে বলছে নিজে কীভাবে জামিন দেবে, চার লাইন: `x-content-type-options: nosniff` (MIME অনুমান নিষেধ), `x-frame-options: DENY` (clickjacking frame নিষেধ), `strict-transport-security` (http downgrade নিষেধ), `content-security-policy: default-src 'self'` (rogue script নিষেধ)। **Path traversal** হলো `join(webroot, '../../etc/passwd')` — `join` জোড়ে, আর dot-এ বেরিয়ে যায়; guard হলো `resolve()` (dot সরিয়ে normalize করে) তারপর `startsWith(webroot + sep)` — কোনো fs কলের *আগে*, রুটের নিচে না থাকলে null। Input decode করুন guard-এর *আগে* — encode করা dot-ও dot। Proxy-র পেছনে আরেকটা hygiene: **X-Forwarded-For** বহন করে proxy-দেখা client IP; বিশ্বাস করুন শুধু নিজের proxy tier থেকে, কাঁচা কখনো নয়।

	<p>
		`timingSafeEqual` সমান-length buffer চায়; আলাদা হলে throw: `Input buffers must have the same length`। Attacker-নিয়ন্ত্রিত input স্ক্রিন ছাড়া পৌঁছালে throw/না-throw পার্থক্য attacker-কে real token-এর length জানিয়ে দেয়। আগে length compare, তারপর byte — দুটোই constant-shape, কোনো আগামি সিগন্যাল নয়।

## তিন প্রতিষেধ, তিন লাইন করে

এই লেসনের ডেমো ফাইলটি চালান:

```bash
node code/5-production-server/5-5-security-hygiene/demo.js
```

ছাপে: `[1]` early-exit compare-এর timing gradient — byte 0 বনাম byte 11 mismatch, লম্বা prefix-এ মাপার মত বেশি সময় (শতাংশ মেশিনভেদে); `[2]` `timingSafeEqual`-এ একই sweep — সমতল, plus length-mismatch throw আর কেন আগে length স্ক্রিন করবেন; `[3]` চার security header যেমন পাঠানো, তাদের মানে; `[4]` `join` webroot ছাড়িয়ে যাচ্ছে, আর resolve-plus-startsWith guard একই path-এ null দিচ্ছে।
