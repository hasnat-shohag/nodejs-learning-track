## What you will learn

A naive secret compare checks byte 0, and bails at the first mismatch — so a guess matching the real token's first 11 bytes takes measurably longer to reject than one failing at byte 0. The demo times 10,000 comparisons per position and the longer-prefix guess runs measurably longer — tens of percent, machine-dependent; the demo prints its own measured value: that gradient is the leak, and an attacker reading it recovers a token one byte at a time. `crypto.timingSafeEqual(a, b)` — note: on `crypto`, not `Buffer` — compares every byte unconditionally, and the same sweep measures flat. **Security headers** are the server telling the browser how to defend itself, four lines: `x-content-type-options: nosniff` (no MIME guessing), `x-frame-options: DENY` (no clickjacking framing), `strict-transport-security` (no http downgrade), `content-security-policy: default-src 'self'` (no rogue scripts). **Path traversal** is `join(webroot, '../../etc/passwd')` — `join` concatenates, and the dots escape the webroot; the guard is `resolve()` (which normalizes the dots away) followed by `startsWith(webroot + sep)` *before* any fs call, returning null when the resolved path is not under the root. Decode input *before* guarding — encoded dots count too. Behind a proxy, one more hygiene item: **X-Forwarded-For** carries the client IP the proxy saw; trust it only from your own proxy tier, never raw.

<Pitfall title="timingSafeEqual throws on length mismatch — and the throw leaks length">
	<p>
		`timingSafeEqual` requires equal-length buffers; different lengths throw `Input buffers must have the same length`. If attacker-controlled input reaches it un-screened, the throw-vs-no-throw difference tells the attacker the real token's length. Compare lengths first, then the bytes — both checks constant-shape, no early signal.
	</p>
</Pitfall>

## Three defenses, three lines each

Run the demo file for this lesson:

```bash
node code/5-production-server/5-5-security-hygiene/demo.js
```

It prints: `[1]` the early-exit compare's timing gradient — mismatch at byte 0 vs byte 11, measurably longer for the longer prefix (the exact percentage is machine-dependent); `[2]` the same sweep under `timingSafeEqual` — flat, plus the length-mismatch throw and why to screen lengths first; `[3]` the four security headers as sent and their meanings; `[4]` `join` escaping the webroot, and the resolve-plus-startsWith guard returning null for the same path.
