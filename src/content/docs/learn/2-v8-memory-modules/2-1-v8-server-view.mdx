## What you will learn

V8 is not an interpreter — it is a tiering compiler. Your code starts as bytecode (Ignition), then hot functions move through Sparkplug (a baseline machine-code tier) up to fully optimized machine code (TurboFan). Optimization decisions are built on **shapes**: objects constructed with the same properties in the same order share one **hidden class**, letting V8 inline property access. The catch is a budget: one read site tolerates up to four distinct hidden classes (polymorphic) before it goes megamorphic and every read pays the slow path. This lesson measures all three facts — the shape budget, the megamorphic step, and the GC spaces your pauses come from.

<Pitfall title="Deopt is silent and per-function">
	<p>
		TurboFan compiles a function <em>assuming</em> the types it has seen. Feed it a different shape once — `null` where objects always were, a fifth constructor where four ran — and V8 throws away the optimized code (deopt) and falls back to Sparkplug baseline code (itself machine code, just unoptimized for this shape). No warning prints; the function just gets slower — see it yourself with `node --trace-deopt-verbose`. The fix is not micro-tuning: keep hot paths monomorphic — one shape, one type, stable arguments.
	</p>
</Pitfall>

## Three measurements

Run the demo file for this lesson:

```bash
node code/2-v8-memory-modules/2-1-v8-server-view/demo.js
```

It prints: `[1]` one construction order vs `[2]` three orders interleaved through the same read site — three forked shapes stay *inside* the inline-cache budget, so reads stay fast; shape forking only costs when it crosses the budget, which `[3]` pins: four shapes at one read site still hold the polymorphic cache, and the 5th distinct hidden class is the megamorphic step where every read pays the slow path; `[4]` the actual V8 heap spaces of the running process, so "young generation" and "old space" stop being vocabulary and become megabytes — plus the heap-wide `heap_size_limit` vs the old-space region `--max-old-space-size` actually constrains.
