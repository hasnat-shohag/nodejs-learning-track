## What you will learn

Every running Node program is one process built from three cooperating layers: **V8** executes your JavaScript, **libuv** owns the event loop and the async I/O machinery, and Node's **bindings** glue the two together in C++. This lesson is a guided tour of that stack — you will map each layer to something you can print from a running process, so the names stop being abstractions.

<Pitfall title="Node is not 'just JavaScript'">
	<p>
		You already know V8 from the browser. But a Node process is V8 <em>plus</em> libuv plus a C++ binding layer — when people say "Node is single-threaded", they mean <strong>your JavaScript</strong> runs on one thread, not that the process is one thread. Keep the three layers separate in your head from the start; every later lesson builds on that split.
	</p>
</Pitfall>

## The three layers, one demo

Run the demo file for this lesson:

```bash
node code/1-node-anatomy-event-loop/1-1-process-anatomy/demo.js
```

It prints the version of each layer your own Node binary carries — V8, libuv (`process.versions.uv`), and the Node bindings — straight from the `process` object.
